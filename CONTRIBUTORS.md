## Recognition

All contributors are recognized and appreciated. Your contributions help make this project better for everyone!

### Contribution Types

We recognize contributions in many forms:

- 💻 **Code**: Pull requests for features, fixes, and improvements
- 📚 **Documentation**: Improving README, guides, and examples
- 🐛 **Bug Reports**: Finding and reporting issues
- 💡 **Ideas**: Suggesting new features and improvements
- 🧪 **Testing**: Testing new features and edge cases
- 🎨 **Design**: UI/UX improvements
- 📢 **Advocacy**: Promoting and discussing the project
